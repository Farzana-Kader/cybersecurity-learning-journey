# Computer Hardware & Architecture

**Status:** Foundation module completed
**Study duration:** 7 study days
**Daily study time:** Approximately 1 hour
**Learning goal:** Build foundational knowledge for MSc Cybersecurity and Digital Forensics.

## Learning Outcomes

After completing this introductory module, I can explain:

1. The main CPU components and the fetch-decode-execute cycle.
2. The purpose of registers, CPU cache, and processor cores.
3. The difference between 32-bit and 64-bit architecture.
4. Virtual memory, paging, and page faults.
5. The role of BIOS/UEFI, Secure Boot, and TPM.
6. The difference between Type 1 and Type 2 hypervisors.
7. The importance of volatile memory in digital forensics.
8. How hardware and architecture concepts support security investigations.

## Cybersecurity Relevance

Understanding computer architecture provides a foundation for investigating malware, analysing system behaviour, understanding memory evidence, and learning reverse engineering.
