## Completed Module: Computer Hardware & Architecture

Topics studied:

- CPU components and the instruction cycle
- Registers, the ALU, and the Program Counter
- CPU cores, clock speed, and cache memory
- 32-bit and 64-bit architecture
- Instruction Set Architecture (ISA)
- Virtual memory, paging, and page faults
- BIOS, UEFI, bootloaders, and Secure Boot
- Trusted Platform Module (TPM) and disk encryption concepts
- Virtualization and hypervisors
- Hardware security threats and side-channel attacks
- Volatile memory and digital forensics

## Cybersecurity Applications

I explored how hardware and operating-system concepts relate to:

- Malware analysis and reverse engineering

- Secure boot and system integrity
- Virtual machine isolation
- Hardware-assisted security
- Investigating suspicious system activity
